How does text split into image patches?

Render text onto a continuous 2D pixel strip and slice it with a sliding window into fixed-size visual tokens (adapted from PIXEL and VisRep).

Exact PangoCairo + Live Canvas.
Presets use exact GoNotoCurrent.ttf PangoCairo strips; custom edits render live in browser.
Patch size (pixels_per_patch) 24 × 24 px
Controls line height and square patch width (window = pixels_per_patch).
Sliding window stride (stride) 24 px (continuous)
Font size & DPI 10pt @ 120 DPI (16.7px)
scaled_px = (dpi / 72) * font_size with 2px horizontal pad.
Font family Noto Sans
Includes automatic Unicode script & symbol fallbacks.
Hover or click any patch to inspect its 24×24 pixel matrix & character span.

    How this browser demo relates to esalesky/minimal-renderer.
    In Python, TextImageGenerator uses PangoCairo + fontconfig with GoNotoCurrent.ttf and fallback fonts to render text onto a cairo.ImageSurface of height pixels_per_patch (default 24px, 10pt @ 120 DPI = 16.67px), pads width to the next multiple of pixels_per_patch, and slices sent_image[:, start:start+window] with step stride. This interactive page executes the same layout and sliding-window geometry live on an HTML5 2D <canvas> using Google Noto web fonts so you can experiment with any text directly in the browser.
